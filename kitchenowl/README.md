### Requirements
- [flutter](https://flutter.dev/docs/get-started/install)
- [fvm](https://fvm.app/documentation/getting-started/installation)

### Setup & Install
- If you haven't already, switch to the frontend folder `cd kitchenowl`
- Install dependencies: `fvm flutter packages get`
- Run app: `fvm flutter run`
